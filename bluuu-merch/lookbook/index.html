05 · Следующие шаги

От файла до полки

  1. Отправить фабрике тех-пак (PDF) и ZIP с артами. Запросить strike-off (пробные оттиски) на реальной ткани по каждому цвету.
  2. Утвердить цвет по Pantone/HEX на оттисках: лазурь 007FFF — самый капризный, проверить при дневном свете.
  3. Получить по одному пред-продакшн образцу (размер S) четырёх первых дизайнов, тест: 5 стирок при 30°, растяжение 30 % без трещин.
  4. Съёмка образцов на борту и в магазине; запуск предзаказа в WhatsApp-рассылке после тура.
  5. Тираж: по размерной сетке XS–L, старт 50–100 шт. на дизайн.
