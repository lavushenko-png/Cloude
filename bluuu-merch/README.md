# Bluuu Tours — мерч-капсула «Боди»

10 дизайнов принта для белого боди-майки (образец с фото), в брендинге [bluuu.tours](https://bluuu.tours): фирменная лазурь `#007FFF`, ночной navy `#0D1B2E`, закатный оранжевый `#FF8A00`, шрифт Petrov Sans. Все арты — вектор в миллиметрах 1:1, текст переведён в кривые.

| Папка | Что внутри |
|---|---|
| `lookbook/` | Презентация коллекции: `index.html` (веб-версия, опубликована как артефакт) и `bluuu-merch-lookbook.pdf` |
| `techpack/` | Тех-пак для фабрики (EN + 中文): `bluuu-bodysuit-techpack.pdf`, схемы размещения `placement-NN.svg` |
| `factory/` | Файлы для печати: `artwork/` (SVG 1:1 мм, PDF, PNG 300 dpi), `labels/` (логотип на спинку, внутренняя этикетка XS–L), `README-factory.txt` |
| `bluuu-factory-pack.zip` | Тех-пак + все файлы печати одним архивом — отправлять в Китай |
| `designs/NN-slug/` | По дизайну: `artwork.svg`, `preview.png`, `mockup.jpg`; плюс `contact-sheet.jpg`, `mockup-sheet.jpg`, `manifest.json` |
| `brand/` | Собранный брендинг: `brand-notes.md`, `palette.png`, `bluuu-logo-nav.svg`, скриншот и мудборд сайта |
| `generator/` | Исходники генератора (Python + Playwright) — править дизайны и пересобирать |

Размещение: центр переда, верх арта на 45–80 мм ниже горловины (точные значения — в тех-паке). Единый для всех: логотип Bluuu 40 × 8,6 мм на спинке под горловиной и печатная внутренняя этикетка 50 × 30 мм.

Pantone в тех-паке — ближайшие ориентиры; фабрика подбирает цвет по HEX/CMYK и присылает пробные оттиски (strike-off) на реальной ткани.
